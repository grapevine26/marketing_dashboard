## 1. 외부 배포 전에 반드시 필요한 것

### 1-1. 데이터 백업
- **현황**: DB가 `.data/db.json` 파일 하나. 파일이 깨지거나 실수로 지우면 복구 수단이 없다.
- **할 일**: `lib/db/index.ts`의 `persist()`에서 저장 직전 파일을 `.data/backups/db-YYYYMMDD-HHmmss.json`으로 복사하고 최근 N개(예: 20개)만 유지. 복구 명령 또는 설정 화면에 "백업 목록/복원" 추가.
- **장기**: 데이터가 수 MB를 넘거나 동시 사용자가 늘면 SQLite(`better-sqlite3`)로 전환. `lib/db/index.ts`의 함수 시그니처를 유지하면 화면 코드는 손대지 않아도 된다.

### 1-2. 공개 폼 스팸 방어 — ✅ 완료 (2026-09-07)
- **허니팟(Honeypot) 방어**: 인플루언서 지원폼(`/apply`), 사전조사(`/pre-survey`), SNS 인테이크(`/sns-intake`)에 보이지 않는 숨김 필드 추가 및 봇 유입 시 무음 성공(HTTP 200) 반환으로 DB 및 웹훅 오염 원천 차단
- **요청 빈도 제한(Rate Limiting)**: `lib/security/rateLimit.ts`에 슬라이딩 윈도우 인메모리 레이트 리미터 구축, 클라이언트 IP 및 토큰 기준 10분당 5회(설문 10회) 초과 시 일시 차단
- **SNS 링크 중복 감지 및 경고 후 허용**: 지원서 접수 시 동일한 SNS 계정 링크가 감지되면 안내 배너 노출, 지원자가 원할 경우 `[기존 내역 유지하고 계속 제출하기]` 버튼을 통해 추가 접수 허용

### 1-3. 공개 토큰 재발급(회수) — ✅ 완료 (2026-09-07)
- **캠페인 4종 토큰 보안 재발급**: `regenerateCampaignToken` 구현 (`apply_form`, `pre_survey`, `applicants_share`, `seeding_sheet_share`), 재발급 즉시 이전 링크 404 차단 및 감사 로그 자동 기록
- **SNS 2종 토큰 보안 재발급**: `regenerateSnsToken` 구현 (`intake`, `approval`), 재발급 즉시 이전 링크 404 차단 및 감사 로그 자동 기록
- **대시보드 UI 및 확인 모달**: `TokenShareBox.tsx` 및 `SnsAccountDetailClient.tsx`에 개별 [재발급] 버튼 및 유출 주의 확인 다이얼로그 탑재, 재발급 즉시 화면 URL 및 복사 링크 실시간 반영

### 1-4. 로그인 (수파베이스 전환 시 팀 권한과 함께 진행 예정)
- 테스트 편의를 위해 의도적으로 보류. 향후 수파베이스(Supabase) 도입 시 기획팀 워크스페이스 팀원 권한 및 인증과 함께 일괄 연동 예정.

## 3. 보고서·내보내기 품질 — ✅ 전체 완료 (2026-09-07)

### 3-1. 결과보고서 PPT 템플릿화 — ✅ 완료
- **현황**: 보고서 PPTX 디자인이 코드에 고정돼 있어 에이전시 로고·색을 넣을 수 없다.
- **할 일**: 행사 운영안처럼 `ppt_templates`에 `kind='report'`를 추가하고 `{{캠페인명}}`, `{{총지원자}}` 같은 치환 항목으로 채우도록 통일. 인플루언서 표는 치환 항목 대신 표 삽입이 필요하므로 엔진에 "표 플레이스홀더" 확장 검토.

### 3-2. 차트 — ✅ 완료
- 조회수·인게이지먼트가 숫자 나열뿐이다. PDF/PPTX에 인플루언서별 막대 차트 하나(pptxgenjs `addChart`, PDF는 직접 그리기)를 추가.

### 3-3. XLSX 내보내기 — ✅ 완료 (2026-09-07)
- `exceljs` 기반 고품질 엑셀 서식 파일 생성 모듈 구축 (`lib/export/xlsx.ts`, `lib/applicants/xlsx.ts`, `lib/seeding/sheetXlsx.ts`)
- 다크 슬레이트 헤더 스타일, 한글 글자수 맞춤 자동 열 너비(Auto Column Width) 계산으로 날짜 `#######` 및 텍스트 잘림 현상 원천 방지
- 상단 1행 틀 고정(Freeze Pane) 및 셀 테두리, 수치/일시/상태별 정렬 서식 적용
- 지원자 및 시딩 관리시트 라우트에 `?format=xlsx` 쿼리 파라미터 지원 및 대시보드 화면에 `[Excel 다운로드]`와 `[CSV]` 버튼 병행 탑재

### 3-4. PDF 여백 — ✅ 완료
- `lib/reports/pdf.ts`의 지표 박스 아래 빈 공간이 넓다. `doc.y` 조정으로 정리(외관 문제, 기능 영향 없음).
