## A. 인플루언서 시딩

- **결과보고서 PDF/PPTX 500 오류 해결**: `createReport()`가 캠페인/지원자/관리시트 스냅샷과 지표를 생성. PPTX는 총평·인플루언서 표를 슬라이드 단위로 페이지 분할. 스냅샷 없는 구버전 보고서는 400과 한국어 안내.
- **공개 페이지 토큰 노출 제거**: 지원폼·사전조사·공유 페이지에 `PublicCampaign` DTO(토큰 없음)만 전달. 액션은 URL 토큰으로 서버에서 다시 조회.
- **광고주 지원자 공유 페이지에서 선정 가능**: `/applicants/[token]`이 대시보드와 같은 테이블을 쓰며 최종선정/예비선정/미선정을 누를 수 있다. 실행 주체는 서버에서 `company`로 고정하고 `status_changed_at` 기록. 연락처·주소는 이 페이지와 CSV(`?token=`)에서 제외.
- 선정 취소 시 `seeding_records`를 삭제하지 않는다. `rejected`(미선정) 상태 추가. 같은 상태 재클릭은 멱등.
- 관리시트: 캠페인 유형별 단계만 표시, D-day 컬럼(서버 KST 계산), 메모 편집, 저장 실패 시 메시지.
- 중복 감지: 서버의 정규화 비교 결과를 그대로 사용(연락처가 달라도 SNS 링크 중복 감지).
- CSV: 상태 라벨 정정(예비선정/미선정), 커스텀 답변·2차활용 동의·선정 변경 주체/시각 컬럼 추가.
- 신청폼: 서버에서 필수값·개인정보 동의·모집 마감·커스텀 문항(숫자/선택/체크박스) 검증. 에디터에서 문항 유형과 선택지 편집 가능.
- 캠페인 상태 변경 드롭다운(허브 상단), 목록에 한글 라벨 표시.

## B. 인플루언서 행사

- 행사 상태 변경(준비중/완료/취소), 기본 정보 수정, 삭제 UI 추가.
- `event_at`은 `datetime-local` 입력을 KST로 해석해 ISO(UTC)로 저장하고, 화면에는 항상 KST로 표시. 오버뷰 캘린더도 KST 날짜로 배치.
- 운영안: 항목별 "AI 초안" 버튼(그 항목만 갱신) + "빈 항목만 AI로 채우기". 저장 전/변경 후에는 다운로드 버튼 비활성.
- PPT 다운로드: 운영안 미저장·템플릿 없음을 기본 템플릿으로 대체하지 않고 400/404 + 한국어 메시지. `DownloadFileButton`이 에러를 화면에 표시.
- 초대자 가져오기 후 전체 새로고침 대신 목록 갱신. 초대자 메모 인라인 편집. 서버 필수값 검증.

## C. SNS 운영

- 광고주 승인 페이지: `pending_approval`만 표시, `media_note`·성과 수치·토큰을 응답에서 제거(`ReviewableSnsContent` DTO). 액션은 토큰으로 계정을 확인하고 콘텐츠 소속·상태를 검증(멱등). 수정 요청 시 코멘트 필수.
- 토큰 검증 없이 노출되던 `submitSnsIntakeAction`/`reviewSnsContentAction`(대시보드 actions) 삭제.
- 콘텐츠 수정/삭제 UI 추가(캘린더 항목 클릭 시 수정 모달). 광고주 수정요청 후 캡션을 고쳐 다시 승인대기로 올릴 수 있다.
- 성과 집계를 월별(게시완료 전환 월 기준)로 변경, 월 선택 + 전체 누적 병기. 음수/소수 입력은 클라이언트·서버 모두 거부. 성과 입력은 게시완료 상태에서만.
- 사전설문 응답 탭이 질문 문구를 표시. 계정 상태(운영중/계약종료) 토글, 계정 정보 수정.
- 콘텐츠 캘린더의 "오늘"은 서버 KST 값을 사용.

## D. 오버뷰

- 소스별 조회를 `{ok, rows}` / `{ok:false}`로 구분하고 실패 시 "일부 데이터를 불러오지 못했습니다: …" 배너 표시(나머지는 정상 렌더링).
- `?month=abc` 같은 잘못된 값은 오늘 달로 폴백. 월 이동은 `<Link>`. 오늘 날짜 강조, "오늘" 버튼, 범례.
- 시딩 항목에 인플루언서 이름 표시, 삭제된 캠페인/행사/계정에 매달린 항목은 조용히 제외.
