# 사용법 페이지(`/guide`) 검수 결과 (2026-09-07)

대상: `app/(dashboard)/guide/page.tsx` (391줄, 정적 페이지).
방법: 가이드에 적힌 문장을 하나씩 실제 코드·화면의 라벨과 대조. 로컬 서버로 다크/라이트/모바일 렌더링 확인.

## 요약

문서 구조와 톤은 좋다. 5단계 워크플로우 구성, 앵커 이동, 설정 화면 바로가기는 정상 동작하고 라이트/다크·모바일에서 깨지는 곳이 없다.

문제는 **내용이 현재 화면보다 뒤처져 있다**는 점이다. 크게 세 종류다.

| 유형 | 건수 | 영향 |
|---|---|---|
| 사실과 다른 서술 | 6건 | 가이드대로 하면 화면에서 그 버튼을 못 찾거나 결과가 다르다 |
| 실제 버튼 이름 불일치 | 11개 | 초보 사용자가 헤맨다 |
| 아예 빠진 기능 | 18개 | 기능이 있는 줄 모르고 안 쓴다 |

## A. 사실과 다른 서술

### A1. "7단계 상태 추적" — 실제는 5단계이고 캠페인 유형마다 다르다
가이드: `7단계 상태 추적: 선정완료 → 발송완료(송장번호) → 가이드전달 → 수령/방문 → 업로드완료`

실제(`lib/seeding/stages.ts`)는 유형별로 5단계다.

- 배송형: 선정완료 → 발송완료 → 가이드전달완료 → 수령완료 → 업로드완료
- 방문형: 선정완료 → **확정완료** → 가이드전달완료 → 방문완료 → 업로드완료

"7"은 내부 타입의 값 개수일 뿐 화면에 7개가 뜨는 일은 없다. 방문형의 `확정완료`는 가이드에 등장하지 않고, `수령/방문`처럼 두 유형을 합쳐 적어서 실제 화면과 대조가 안 된다.

### A2. 행사 PPT "3장의 와이드 다크테마 PPTX가 출력됩니다" — 템플릿 기반으로 바뀌었다
실제 흐름은 운영안 탭에서 **적용할 PPT 템플릿을 먼저 고르고**, 항목을 채워 **저장**한 뒤 다운로드하는 것이다. 결과물의 슬라이드 수와 디자인은 고른 템플릿이 결정한다. 저장 전에 누르면 "저장된 운영안이 없습니다", 템플릿이 없으면 "행사용 PPT 템플릿이 없습니다"가 뜬다. 가이드에는 템플릿 선택 단계 자체가 없어서, 설정에서 템플릿을 올려야 한다는 사실을 알 수 없다.

### A3. 광고주 공유 링크의 권한을 축소해서 설명한다
가이드: "광고주도 로그인 없이 실시간 지원자 명단을 **열람**할 수 있습니다."

실제로 광고주는 그 페이지에서 최종선정·예비선정·미선정을 **직접 누를 수 있다**(연락처·주소·에이전시 메모는 가려짐). 권한 범위를 실제보다 좁게 적어두면 링크를 보내는 사람이 위험을 오판한다.

### A4. 선정 버튼을 3개만 설명한다 — 상태에 따라 버튼이 바뀐다
실제 지원자 테이블의 버튼은 상태별로 다르다.

| 현재 상태 | 표시되는 버튼 |
|---|---|
| 지원완료 | 최종선정 / 예비선정 / **미선정** |
| 최종선정 | 선정 취소 / **예비로 변경** |
| 예비선정 | **최종선정 승격** / 예비 취소 |

가이드에는 미선정, 예비로 변경, 최종선정 승격이 없다.

### A5. 행사는 캠페인 없이 개설할 수 없다
Quick Start 2번은 "[인플루언서 행사]에서 행사를 개설하고"라고 안내하지만, 실제 개설 모달은 연계 캠페인을 필수로 요구하고 캠페인이 없으면 "행사를 개설하려면 먼저 연계할 마케팅 캠페인이 필요합니다"만 보여준다. 처음 쓰는 사람이 가이드대로 행사부터 가면 막힌다.

### A6. 사용자에게 내부 경로를 그대로 노출한다
"내부 `/campaigns/[id]/pre-survey`에서 확인", "`?month=YYYY-MM` 단위로 이동" 두 곳은 개발자 표기다. 화면 이름("사전조사 관리", 캘린더의 월 이동 화살표)으로 바꾸는 편이 낫다.

## C. 가이드에 빠진 기능

존재하는데 문서에 한 줄도 없는 것들이다. 특히 앞의 다섯 개는 모르고 넘어가면 실무에서 손해가 크다.

1. **공유 링크 재발급** — 링크가 유출됐을 때 이전 링크를 즉시 무효화하는 유일한 수단인데 설명이 없다.
2. **로그인이 없다는 전제** — 링크를 아는 사람은 누구나 들어온다. 링크 취급 주의와 재발급을 함께 안내해야 한다.
3. **AI에는 API 키가 필요하다** — `GEMINI_API_KEY`가 없으면 모든 AI 버튼이 "AI 제안 실패 — 직접 입력해주세요."로 떨어진다. 가이드는 AI가 항상 되는 것처럼 쓰여 있다.
4. **지원 폼 스팸 제한** — 같은 IP에서 10분에 5회까지만 접수된다. 담당자가 폼을 테스트하다 막히면 고장으로 오해한다.
5. **데이터 백업/복원** — `.data/backups`에 자동 스냅샷이 쌓이고 `npm run db:restore`로 되돌린다.
6. 캠페인 상태 6단계(준비중/모집중/선정중/시딩 진행중/보고서 작성/종료)
7. 신청폼 접수 중단 토글(모집 마감 처리)
8. 지원자 검색, 팔로워순 정렬, 상태 필터 탭, 20건 페이지네이션
9. 에이전시 메모(광고주 공유 페이지에는 안 보임)
10. 안내 메시지 템플릿 — [안내문] 버튼으로 이름·채널이 치환된 문구 복사
11. XLSX 내보내기 (가이드는 CSV만 언급)
12. 마감 알림 웹훅(Slack/Discord) + 테스트 발송
13. 활동 기록(감사 로그) — 캠페인 허브 하단
14. SNS 운영안(제안서) 페이지와 PPT 다운로드
15. SNS 시안 미디어 첨부 — 이미지·영상을 올리면 광고주 승인 페이지에서 바로 본다
16. SNS 계정 정보 수정, 운영중/계약종료 상태 전환, 사전설문 응답 탭
17. 결과보고서는 [새 결과보고서 생성]으로 스냅샷을 떠야 하고, PPTX는 템플릿을 고를 수 있다
18. 캘린더 날짜 클릭 시 그 날 일정 모달, 사이드바의 다크/화이트 테마 전환, 캠페인·SNS 계정 삭제(연쇄 삭제 범위)

## D. 이해도 측면에서 보완할 것

- **링크 4종 정리표가 없다.** 누구에게 보내는지, 무엇을 할 수 있는지, 무엇이 가려지는지를 한 표로 보여주는 게 이 제품에서 가장 필요한 설명이다. SNS 쪽 링크 2종(사전설문·승인)도 마찬가지.
- **순서 의존성을 명시하지 않는다.** 관리시트는 최종선정 후에 채워지고, 보고서는 스냅샷 생성 후에 열리며, PPT는 저장과 템플릿 선택이 끝나야 받아진다. 지금은 각 단계가 독립적으로 읽힌다.
- **PPT 템플릿이 행사·SNS·보고서 3종으로 나뉜다**는 설명이 없어서, 설정 화면에서 어떤 종류를 올려야 하는지 알 수 없다.
- 배송형과 방문형에서 화면이 달라진다는 점(입력 항목, 단계 이름)이 한 줄도 없다.

## E. 문서 자체의 결함

- **공백 누락 2곳**: 실제 렌더링이 "인플루언서 초청 행사(RSVP),SNS 공식 채널", "관리하고,Gemini AI와"로 붙어 나온다. JSX에서 줄 끝 공백이 지워져서 생긴 것이라 문자열을 합치거나 `{" "}`를 넣어야 한다.
- 미사용 아이콘 import 12개(`Sparkles`, `ArrowRight`, `FileQuestion` 등)가 린트 경고로 남아 있다.
- 정상: 앵커 5개 이동, 설정 3개 카드 링크, 모바일 가로 스크롤 없음, 라이트/다크 모두 렌더링 정상, 사이드바 메뉴 이름과 가이드의 메뉴 표기 일치.

## 권장 처리 순서

1. A1~A6 여섯 곳 문장 수정 (30분). 사실 오류라 가장 급하다.
2. E의 공백 누락 2곳과 미사용 import 정리 (5분).
3. B의 버튼 이름 11개를 화면 문구와 일치시키기 (30분).
4. 링크 4종 정리표 + "시작하기 전에"(캠페인 먼저 생성, AI 키, 링크 관리, 스팸 제한) 블록 추가 (1시간).
5. C의 누락 기능을 각 섹션에 흡수. 특히 재발급·웹훅·미디어 첨부·메모·XLSX·SNS 운영안 (2시간).

## 적용 결과 (2026-09-07, 검수 직후 전면 재작성)

가이드 페이지를 실제 화면 기준으로 다시 썼다. 391줄 → 727줄.

- **A1~A6 사실 오류 6건 정정.** 단계는 배송형·방문형 5단계로 나눠 표시하고, 그 목록을 `lib/seeding/stages.ts`에서 직접 import해 코드가 바뀌면 가이드도 따라 바뀌게 했다. 행사 PPT는 템플릿 선택 → 저장 → 다운로드 순서로 고쳤고, 광고주 공유 링크가 선정까지 가능하다는 점, 행사는 캠페인이 있어야 개설된다는 점을 명시했다. 내부 경로 표기는 화면 이름으로 교체했다.
- **B 버튼 이름 11개**를 화면 문구와 일치시켰다.
- **새 섹션 3개 추가**: "시작하기 전에 꼭 알아둘 4가지"(로그인 없음·링크 재발급, 캠페인 선행, AI 키, 10분 5회 제한), "공유 링크 한눈에 보기"(링크 6종 × 받는 사람/할 수 있는 일/가려지는 정보 표), "자주 막히는 곳"(8문답).
- **C 누락 기능 18개**를 각 섹션과 "알아두면 좋은 기능"에 흡수했다. 웹훅, 활동 기록, 캠페인 상태·삭제 범위, 테마, 백업, 검색·정렬·페이지네이션, 메모, 안내문, XLSX, 시안 미디어, SNS 운영안, 접수 중단, 보고서 스냅샷·템플릿 선택.
- **E 문서 결함**: 공백 누락 2곳 해결, 미사용 import 12개 제거.

검증: 타입체크·린트 0, 유닛 79, E2E 20, 빌드 통과. 라이트/다크/모바일 렌더링과 앵커 8개 이동 확인, 가로 스크롤 없음.
